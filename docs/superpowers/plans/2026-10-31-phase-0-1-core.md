# Hengst Client Phase 0 + 1 (Gerüst und Kern) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein öffentliches Repo `clemensjl/hengst-client` mit CI, und eine CLI `hengst`, die jede Minecraft-Java-Version aus Mojangs Versionsliste (Pre-Classic bis 26.x) vollständig herunterlädt, die passende Java-Laufzeit installiert und das Spiel startet.

**Architecture:** Rust-Workspace mit einer Bibliothek `hengst-core` (Module: paths, download, manifest, rules, version, libraries, assets, java, args, launch) und einem dünnen CLI-Binary `hengst`. Alle Netzwerkzugriffe laufen über einen `Downloader` mit SHA1-Prüfung, Wiederholung und begrenzter Parallelität. Java-Laufzeiten kommen aus Mojangs eigenem Runtime-Manifest (gleiche Laufzeiten wie im offiziellen Launcher). In Phase 1 gibt es nur ein Offline-Entwicklerkonto, das echte Spielen ohne Microsoft-Login ist hinter dem Cargo-Feature `dev-offline` gesperrt.

**Tech Stack:** Rust 1.97 (Edition 2021), tokio, reqwest (rustls), serde/serde_json, sha1, md-5, zip 2, regex, dirs, clap 4, thiserror, anyhow. Tests: wiremock, tempfile. CI: GitHub Actions auf `windows-latest`.

**Spec:** `docs/PLAN.md` (Gesamtplan, Abschnitte 3, 4, 8, 9, 10, 11)

use std::path::{Path, PathBuf};

/// Layout of the launcher data directory.
#[derive(Clone, Debug)]
pub struct Paths {

}

impl Paths {
    pub fn new(root: impl Into<PathBuf>) -> Self {
        Self { root: root.into() }
    }

    /// `HENGST_HOME` if set, otherwise `%APPDATA%\HengstClient`.
    pub fn default_root() -> PathBuf {
        if let Some(p) = std::env::var_os("HENGST_HOME") {
            return PathBuf::from(p);
        }
        dirs::data_dir()
            .unwrap_or_else(|| PathBuf::from("."))
            .join("HengstClient")
    }

    pub fn root(&self) -> &Path {
        &self.root
    }

    pub fn manifest_file(&self) -> PathBuf {
        self.root.join("meta").join("version_manifest_v2.json")
    }

    pub fn version_json(&self, id: &str) -> PathBuf {
        self.root.join("meta").join("versions").join(format!("{id}.json"))

    pub fn client_jar(&self, id: &str) -> PathBuf {
        self.root.join("versions").join(id).join(format!("{id}.jar"))

    pub fn libraries(&self) -> PathBuf {
        self.root.join("libraries")
    }

    pub fn assets(&self) -> PathBuf {
        self.root.join("assets")

use crate::{Error, Result};
use futures::stream::{self, StreamExt, TryStreamExt};
use sha1::{Digest, Sha1};
use std::collections::HashSet;
use std::path::{Path, PathBuf};
use std::time::Duration;

pub const USER_AGENT: &str = concat!(
    "HengstClient/",
    env!("CARGO_PKG_VERSION"),
    " (github.com/clemensjl/hengst-client)"
);

pub fn http_client() -> reqwest::Client {
    reqwest::Client::builder()
        .user_agent(USER_AGENT)
        .connect_timeout(Duration::from_secs(15))
        .timeout(Duration::from_secs(300))
        .build()
        .expect("static reqwest configuration is valid")
}

/// One file to fetch. `sha1 = None` means "existing file is good enough".
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Download {
    pub url: String,
    pub path: PathBuf,
    pub sha1: Option<String>,
}

#[derive(Clone)]
pub struct Downloader {
    client: reqwest::Client,
    concurrency: usize,
    retries: u32,
}

impl Downloader {
    pub fn new(client: reqwest::Client) -> Self {
        Self {
            client,
            concurrency: 16,
            retries: 3,
        }
    }

    pub fn with_concurrency(mut self, n: usize) -> Self {
        self.concurrency = n.max(1);
        self
    }

    pub fn client(&self) -> &reqwest::Client {
        &self.client
    }

    /// Fetches all items (deduplicated by target path). Returns how many were actually downloaded.
    pub async fn fetch_all(&self, items: Vec<Download>) -> Result<usize> {
        let mut seen = HashSet::new();
        let unique: Vec<Download> = items
            .into_iter()
            .filter(|d| seen.insert(d.path.clone()))
            .collect();
        let results: Vec<bool> = stream::iter(unique)
            .map(|item| {
                let this = self.clone();
                async move { this.fetch_one(&item).await }
            })
            .buffer_unordered(self.concurrency)
            .try_collect()
            .await?;
        Ok(results.into_iter().filter(|d| *d).count())
    }

    /// Returns `Ok(false)` if the file already existed and was valid.
    pub async fn fetch_one(&self, item: &Download) -> Result<bool> {
        if is_valid(&item.path, item.sha1.as_deref()).await? {
            return Ok(false);
        }
        let mut attempt = 0;
        loop {
            match self.try_fetch(item).await {
                Ok(()) => return Ok(true),
                Err(e) if attempt + 1 < self.retries && is_retryable(&e) => {
                    attempt += 1;
                    tokio::time::sleep(Duration::from_millis(300 * u64::from(attempt))).await;
                }
                Err(e) => return Err(e),
            }
        }
    }

    async fn try_fetch(&self, item: &Download) -> Result<()> {
        let bytes = get_bytes(&self.client, &item.url).await?;
        if let Some(expected) = &item.sha1 {
            let actual = sha1_hex(&bytes);
            if !actual.eq_ignore_ascii_case(expected) {
                return Err(Error::Checksum {
                    path: item.path.clone(),
                    expected: expected.clone(),
                    actual,
                });
            }
        }
        if let Some(parent) = item.path.parent() {
            tokio::fs::create_dir_all(parent).await?;
        }
        let mut tmp = item.path.clone().into_os_string();
        tmp.push(".part");
        let tmp = PathBuf::from(tmp);
        tokio::fs::write(&tmp, &bytes).await?;
        tokio::fs::rename(&tmp, &item.path).await?;
        Ok(())
    }
}

pub async fn get_bytes(client: &reqwest::Client, url: &str) -> Result<Vec<u8>> {
    let http = |source| Error::Http {
        url: url.to_string(),
        source,
    };
    let resp = client.get(url).send().await.map_err(http)?;
    let status = resp.status();
    if !status.is_success() {
        return Err(Error::Status {
            url: url.to_string(),
            status: status.as_u16(),
        });
    }
    Ok(resp.bytes().await.map_err(http)?.to_vec())
}

fn is_retryable(e: &Error) -> bool {
    match e {
        Error::Http { .. } | Error::Checksum { .. } => true,
        Error::Status { status, .. } => *status >= 500 || *status == 429,
        _ => false,
    }
}

async fn is_valid(path: &Path, sha1: Option<&str>) -> Result<bool> {
    if !path.is_file() {
        return Ok(false);
    }
    let Some(expected) = sha1 else {
        return Ok(true);
    };
    let p = path.to_owned();
    let actual = tokio::task::spawn_blocking(move || sha1_file(&p))
        .await
        .expect("hash task panicked")?;
    Ok(actual.eq_ignore_ascii_case(expected))
}

pub fn sha1_hex(data: &[u8]) -> String {
    hex::encode(Sha1::digest(data))
}

pub fn sha1_file(path: &Path) -> Result<String> {
    let mut file = std::fs::File::open(path)?;
    let mut hasher = Sha1::new();
    std::io::copy(&mut file, &mut hasher)?;
    Ok(hex::encode(hasher.finalize()))
}

use serde::Deserialize;
use std::collections::HashMap;

#[derive(Deserialize, Clone, Debug, PartialEq, Eq)]
#[serde(rename_all = "lowercase")]
pub enum Action {
    Allow,
    Disallow,
}

#[derive(Deserialize, Clone, Debug, Default)]
pub struct OsRule {
    pub name: Option<String>,
    pub arch: Option<String>,
    pub version: Option<String>,
}

#[derive(Deserialize, Clone, Debug)]
pub struct Rule {
    pub action: Action,
    pub os: Option<OsRule>,
    pub features: Option<HashMap<String, bool>>,
}

/// The machine the game runs on, in Mojang's vocabulary.
#[derive(Clone, Debug)]
pub struct Env {
    pub os_name: String,
    pub arch: String,
    pub os_version: String,
    pub features: HashMap<String, bool>,
}

impl Env {
    pub fn current() -> Self {
        let os_name = match std::env::consts::OS {
            "windows" => "windows",
            "macos" => "osx",
            _ => "linux",
        };
        let arch = match std::env::consts::ARCH {
            "x86" => "x86",
            "aarch64" => "arm64",
            other => other,
        };
        // Windows 10 and 11 both report 10.0 to Java, which is what Mojang's rules match against.
        let os_version = if os_name == "windows" { "10.0" } else { "" };
        Self {
            os_name: os_name.into(),
            arch: arch.into(),
            os_version: os_version.into(),
            features: HashMap::new(),
        }
    }

    pub fn windows_x64() -> Self {
        Self {
            os_name: "windows".into(),
            arch: "x86_64".into(),
            os_version: "10.0".into(),
            features: HashMap::new(),
        }
    }

    /// Value for `${arch}` in legacy native classifiers.
    pub fn arch_bits(&self) -> &'static str {
        if self.arch == "x86" {
            "32"
        } else {
            "64"
        }
    }

    pub fn classpath_separator(&self) -> &'static str {
        if self.os_name == "windows" {
            ";"
        } else {
            ":"
        }
    }
}

impl Rule {
    fn matches(&self, env: &Env) -> bool {
        if let Some(os) = &self.os {
            if os.name.as_ref().is_some_and(|n| n != &env.os_name) {
                return false;
            }
            if os.arch.as_ref().is_some_and(|a| a != &env.arch) {
                return false;
            }
            if let Some(v) = &os.version {
                match Regex::new(v) {
                    Ok(re) if re.is_match(&env.os_version) => {}
                    _ => return false,
                }
            }
        }
        if let Some(features) = &self.features {
            for (key, wanted) in features {
                if env.features.get(key).copied().unwrap_or(false) != *wanted {
                    return false;
                }
            }
        }
        true
    }
}

/// Mojang semantics: no rules means allowed; otherwise the last matching rule decides, default deny.
pub fn rules_allow(rules: &[Rule], env: &Env) -> bool {
    if rules.is_empty() {
        return true;
    }
    let mut allowed = false;
    for rule in rules {
        if rule.matches(env) {
            allowed = rule.action == Action::Allow;
        }
    }
    allowed
}

pub const MANIFEST_URL: &str = "https://piston-meta.mojang.com/mc/game/version_manifest_v2.json";

pub struct VersionManifest {

#[derive(Deserialize, Serialize, Clone, Debug)]
pub struct VersionEntry {
    pub id: String,
    #[serde(rename = "type")]
    pub kind: VersionKind,
    pub url: String,
    pub sha1: String,
    #[serde(rename = "releaseTime")]
    pub release_time: String,
}

#[derive(Deserialize, Serialize, Clone, Copy, Debug, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum VersionKind {
    Release,
    Snapshot,
    OldBeta,
    OldAlpha,
    #[serde(other)]
    Other,
}

impl VersionManifest {
    /// Finds a version by id. Accepts `latest`/`latest-release` and `latest-snapshot`.
    pub fn find(&self, id: &str) -> Option<&VersionEntry> {
        let id = match id {
            "latest" | "latest-release" => self.latest.release.as_str(),
            "latest-snapshot" => self.latest.snapshot.as_str(),
            other => other,
        };
        self.versions.iter().find(|v| v.id == id)
    }
}

/// Downloads the manifest and caches it. Falls back to the cache when the network fails.
pub async fn fetch_manifest(
    client: &reqwest::Client,
    paths: &Paths,
    url: &str,
) -> Result<VersionManifest> {
    let cache = paths.manifest_file();
    match get_bytes(client, url).await {
        Ok(bytes) => {
            let manifest: VersionManifest = serde_json::from_slice(&bytes)?;
            if let Some(parent) = cache.parent() {
                tokio::fs::create_dir_all(parent).await?;
            }
            tokio::fs::write(&cache, &bytes).await?;
            Ok(manifest)
        }
        Err(e @ (Error::Http { .. } | Error::Status { .. })) => {
            if cache.is_file() {
                Ok(serde_json::from_slice(&tokio::fs::read(&cache).await?)?)
            } else {
                Err(e)
            }
        }
        Err(e) => Err(e),
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct NativeJar {
    pub path: PathBuf,
    pub exclude: Vec<String>,

#[derive(Debug, Default)]
pub struct ResolvedLibraries {
    pub classpath: Vec<PathBuf>,
    pub natives: Vec<NativeJar>,
    pub downloads: Vec<Download>,

/// `group:artifact:version[:classifier][@ext]` to a repository-relative path.
pub fn maven_path(name: &str) -> Option<String> {
    let (coords, ext) = name.split_once('@').unwrap_or((name, "jar"));
    let parts: Vec<&str> = coords.split(':').collect();
    if parts.len() < 3 {
        return None;
    }
    let (group, artifact, version) = (parts[0], parts[1], parts[2]);
    let file = match parts.get(3) {
        Some(classifier) => format!("{artifact}-{version}-{classifier}.{ext}"),
        None => format!("{artifact}-{version}.{ext}"),
    };
    Some(format!("{}/{artifact}/{version}/{file}", group.replace('.', "/")))
}

fn is_native_classifier(name: &str) -> bool {
    let coords = name.split('@').next().unwrap_or(name);
    coords
        .split(':')
        .nth(3)
        .is_some_and(|c| c.starts_with("natives-"))
}

pub fn resolve(libs: &[Library], env: &Env, paths: &Paths) -> ResolvedLibraries {
    let lib_dir = paths.libraries();
    let mut out = ResolvedLibraries::default();
    let mut queued = HashSet::new();
    let mut push = |out: &mut ResolvedLibraries, d: Download| {
        if queued.insert(d.path.clone()) {
            out.downloads.push(d);
        }
    };

    for lib in libs {
        if !rules_allow(&lib.rules, env) {
            continue;
        }
        let exclude = lib.extract.clone().unwrap_or_default().exclude;

        // Pre-1.19 style: natives live in a classifier selected per OS.
        if let Some(classifier) = lib.natives.as_ref().and_then(|n| n.get(&env.os_name)) {
            let classifier = classifier.replace("${arch}", env.arch_bits());
            let artifact = lib
                .downloads
                .as_ref()
                .and_then(|d| d.classifiers.as_ref())
                .and_then(|c| c.get(&classifier));
            if let Some(a) = artifact {
                let path = lib_dir.join(&a.path);
                push(&mut out, Download { url: a.url.clone(), path: path.clone(), sha1: Some(a.sha1.clone()) });
                out.natives.push(NativeJar { path, exclude: exclude.clone() });
            }
        }

        let artifact = match &lib.downloads {
            Some(d) => d.artifact.as_ref().map(|a| (a.path.clone(), a.url.clone(), Some(a.sha1.clone()))),
            None => maven_path(&lib.name).map(|rel| {
                let base = lib.url.clone().unwrap_or_else(|| LIBRARIES_URL.to_string());
                let base = if base.ends_with('/') { base } else { format!("{base}/") };
                (rel.clone(), format!("{base}{rel}"), None)
            }),
        };
        if let Some((rel, url, sha1)) = artifact {
            let path = lib_dir.join(&rel);
            push(&mut out, Download { url, path: path.clone(), sha1 });
            if is_native_classifier(&lib.name) {
                out.natives.push(NativeJar { path: path.clone(), exclude: exclude.clone() });
            }
            if !out.classpath.contains(&path) {
                out.classpath.push(path);
            }
        }
    }
    out
}

fn is_native_file(name: &str) -> bool {
    let n = name.to_ascii_lowercase();
    [".dll", ".so", ".dylib", ".jnilib"].iter().any(|ext| n.ends_with(ext))
}

/// Extracts native libraries flat into `dest` (only file names, so no path traversal).
pub fn extract_natives(natives: &[NativeJar], dest: &Path) -> Result<()> {
    std::fs::create_dir_all(dest)?;
    for jar in natives {
        let mut zip = zip::ZipArchive::new(std::fs::File::open(&jar.path)?)?;
        for i in 0..zip.len() {
            let mut entry = zip.by_index(i)?;
            if entry.is_dir() {
                continue;
            }
            let name = entry.name().to_string();
            if name.starts_with("META-INF/") || jar.exclude.iter().any(|e| name.starts_with(e.as_str())) {
                continue;
            }
            if !is_native_file(&name) {
                continue;
            }
            let Some(file_name) = Path::new(&name).file_name() else {
                continue;
            };
            let mut out = std::fs::File::create(dest.join(file_name))?;
            std::io::copy(&mut entry, &mut out)?;
        }
    }
    Ok(())
}

use crate::download::{Download, Downloader};
use crate::paths::Paths;
use crate::version::AssetIndexRef;
use crate::Result;
use serde::Deserialize;
use std::collections::{HashMap, HashSet};
use std::path::{Path, PathBuf};

pub const RESOURCES_URL: &str = "https://resources.download.minecraft.net";

#[derive(Deserialize, Debug)]
pub struct AssetIndex {
    pub objects: HashMap<String, AssetObject>,
    #[serde(default, rename = "virtual")]
    pub is_virtual: bool,
    #[serde(default)]
    pub map_to_resources: bool,
}

#[derive(Deserialize, Debug, Clone)]
pub struct AssetObject {
    pub hash: String,
    pub size: u64,
}

/// Where the game should look for assets (`${assets_root}` and `${game_assets}`).
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct AssetsLayout {
    pub index_id: String,
    pub assets_root: PathBuf,
    pub game_assets: PathBuf,
}

pub async fn install_assets(
    dl: &Downloader,
    paths: &Paths,
    index: &AssetIndexRef,
    game_dir: &Path,
    base_url: &str,
) -> Result<AssetsLayout> {
    let index_path = paths.asset_index(&index.id);
    dl.fetch_one(&Download {
        url: index.url.clone(),
        path: index_path.clone(),
        sha1: Some(index.sha1.clone()),
    })
    .await?;
    let parsed: AssetIndex = serde_json::from_slice(&tokio::fs::read(&index_path).await?)?;

    let base = base_url.trim_end_matches('/');
    let mut seen = HashSet::new();
    let downloads: Vec<Download> = parsed
        .objects
        .values()
        .filter(|o| o.hash.len() > 2 && seen.insert(o.hash.clone()))
        .map(|o| Download {
            url: format!("{base}/{}/{}", &o.hash[..2], o.hash),
            path: paths.asset_object(&o.hash),
            sha1: Some(o.hash.clone()),
        })
        .collect();
    dl.fetch_all(downloads).await?;

    let assets_root = paths.assets();
    let game_assets = if parsed.map_to_resources {
        let dest = game_dir.join("resources");
        copy_named(&parsed, paths, &dest)?;
        dest
    } else if parsed.is_virtual {
        let dest = assets_root.join("virtual").join(&index.id);
        copy_named(&parsed, paths, &dest)?;
        dest
    } else {
        assets_root.clone()
    };
    Ok(AssetsLayout {
        index_id: index.id.clone(),
        assets_root,
        game_assets,
    })
}

/// Old versions read assets by name, so copy hashed objects to readable paths.
fn copy_named(index: &AssetIndex, paths: &Paths, dest: &Path) -> Result<()> {
    for (name, obj) in &index.objects {
        if name.contains("..") {
            continue;
        }
        let target = dest.join(name);
        if target.is_file() {
            continue;
        }
        if let Some(parent) = target.parent() {
            std::fs::create_dir_all(parent)?;
        }
        std::fs::copy(paths.asset_object(&obj.hash), &target)?;
    }
    Ok(())
}

use crate::download::{get_bytes, Download, Downloader};
use crate::paths::Paths;
use crate::rules::Env;
use crate::version::VersionJson;
use crate::{Error, Result};
use serde::Deserialize;
use std::collections::HashMap;
use std::path::PathBuf;

pub const RUNTIME_INDEX_URL: &str =
    "https://piston-meta.mojang.com/v1/products/java-runtime/2ec0cc96c44e5a76b9c8b7c39df7210883d12871/all.json";

#[derive(Deserialize)]
struct RuntimeEntry {
    manifest: ManifestRef,
}

#[derive(Deserialize)]
struct ManifestRef {
    sha1: String,
    url: String,
}

#[derive(Deserialize)]
struct RuntimeManifest {
    files: HashMap<String, RuntimeFile>,
}

#[derive(Deserialize)]
struct RuntimeFile {
    #[serde(rename = "type")]
    kind: String,
    downloads: Option<RuntimeDownloads>,
}

#[derive(Deserialize)]
struct RuntimeDownloads {
    raw: RawFile,
}

#[derive(Deserialize)]
struct RawFile {
    sha1: String,
    url: String,
}

pub fn platform_key(env: &Env) -> &'static str {
    match (env.os_name.as_str(), env.arch.as_str()) {
        ("windows", "x86") => "windows-x86",
        ("windows", "arm64") => "windows-arm64",
        ("windows", _) => "windows-x64",
        ("osx", "arm64") => "mac-os-arm64",
        ("osx", _) => "mac-os",
        ("linux", "x86") => "linux-i386",
        _ => "linux",
    }
}

/// Versions without `javaVersion` (before 1.17) run on Java 8 (`jre-legacy`).
pub fn component_for(v: &VersionJson) -> String {
    v.java_version
        .as_ref()
        .map(|j| j.component.clone())
        .unwrap_or_else(|| "jre-legacy".to_string())
}

/// `java.exe` keeps game output on the console for the CLI. The desktop app will switch to `javaw.exe`.
pub fn java_executable(paths: &Paths, env: &Env, component: &str) -> PathBuf {
    let bin = paths.java_runtime(component).join("bin");
    if env.os_name == "windows" {
        bin.join("java.exe")
    } else {
        bin.join("java")
    }
}

pub async fn ensure_runtime(
    dl: &Downloader,
    paths: &Paths,
    env: &Env,
    component: &str,
    index_url: &str,
) -> Result<PathBuf> {
    let exe = java_executable(paths, env, component);
    let index: HashMap<String, HashMap<String, Vec<RuntimeEntry>>> =
        match get_bytes(dl.client(), index_url).await {
            Ok(bytes) => serde_json::from_slice(&bytes)?,
            Err(e @ (Error::Http { .. } | Error::Status { .. })) => {
                return if exe.is_file() { Ok(exe) } else { Err(e) };
            }
            Err(e) => return Err(e),
        };
    let platform = platform_key(env);
    let entry = index
        .get(platform)
        .and_then(|m| m.get(component))
        .and_then(|list| list.first())
        .ok_or_else(|| Error::NoRuntime {
            component: component.to_string(),
            platform: platform.to_string(),
        })?;

    let root = paths.java_runtime(component);
    let manifest_path = root.join(".manifest.json");
    dl.fetch_one(&Download {
        url: entry.manifest.url.clone(),
        path: manifest_path.clone(),
        sha1: Some(entry.manifest.sha1.clone()),
    })
    .await?;
    let manifest: RuntimeManifest = serde_json::from_slice(&tokio::fs::read(&manifest_path).await?)?;

    let mut downloads = Vec::new();
    for (rel, file) in &manifest.files {
        if rel.contains("..") {
            continue;
        }
        match (file.kind.as_str(), &file.downloads) {
            ("directory", _) => tokio::fs::create_dir_all(root.join(rel)).await?,
            ("file", Some(d)) => downloads.push(Download {

#[derive(Clone, Debug)]
pub struct Account {
    pub name: String,
    pub uuid: String,
    pub access_token: String,
    pub user_type: String,
    pub xuid: String,
}

impl Account {
    /// Offline account for local development. UUID matches Java's
    /// `UUID.nameUUIDFromBytes("OfflinePlayer:" + name)` like vanilla servers use.
    pub fn offline(name: &str) -> Self {
        let mut d: [u8; 16] = Md5::digest(format!("OfflinePlayer:{name}").as_bytes()).into();
        d[6] = (d[6] & 0x0f) | 0x30;
        d[8] = (d[8] & 0x3f) | 0x80;
        Self {
            name: name.to_string(),
            uuid: hex::encode(d),
            access_token: "0".into(),
            user_type: "legacy".into(),
            xuid: "0".into(),
        }
    }
}

#[derive(Clone, Debug)]
pub struct LaunchContext {
    pub account: Account,
    pub game_dir: PathBuf,
    pub natives_dir: PathBuf,
    pub libraries_dir: PathBuf,
    /// Libraries first, client jar last.
    pub classpath: Vec<PathBuf>,
    pub assets: AssetsLayout,
    pub log_config: Option<PathBuf>,
    pub env: Env,
    pub memory_mb: u32,
}

const WINDOWS_HEAPDUMP: &str =
    "-XX:HeapDumpPath=MojangTricksIntelDriversForPerformance_javaw.exe_minecraft.exe.heapdump";
const LEGACY_JVM: &[&str] = &["-Djava.library.path=${natives_directory}", "-cp", "${classpath}"];

/// Everything after the java executable: JVM args, main class, game args.
pub fn build_args(v: &VersionJson, ctx: &LaunchContext) -> Vec<String> {
    let vars = variables(v, ctx);
    let mut out = vec![
        format!("-Xmx{}M", ctx.memory_mb),
        format!("-Xms{}M", ctx.memory_mb.min(512)),
    ];
    match v.arguments.as_ref().filter(|a| !a.jvm.is_empty()) {
        Some(a) => out.extend(expand(&a.jvm, &ctx.env)),
        None => {
            if ctx.env.os_name == "windows" {
                out.push(WINDOWS_HEAPDUMP.to_string());
            }
            out.extend(LEGACY_JVM.iter().map(|s| s.to_string()));
        }
    }
    let log_arg = v.logging.as_ref().and_then(|l| l.client.as_ref()).map(|c| &c.argument);
    if let (Some(path), Some(arg)) = (&ctx.log_config, log_arg) {
        out.push(arg.replace("${path}", &path.to_string_lossy()));
    }
    out.push(v.main_class.clone());
    match (&v.arguments, &v.minecraft_arguments) {
        (Some(a), _) if !a.game.is_empty() => out.extend(expand(&a.game, &ctx.env)),
        (_, Some(legacy)) => out.extend(legacy.split_whitespace().map(String::from)),
        _ => {}
    }
    out.into_iter().map(|s| substitute(&s, &vars)).collect()
}

fn expand(args: &[Argument], env: &Env) -> Vec<String> {
    let mut out = Vec::new();
    for arg in args {
        match arg {
            Argument::Plain(s) => out.push(s.clone()),
            Argument::Conditional { rules, value } if rules_allow(rules, env) => match value {
                ArgValue::One(s) => out.push(s.clone()),
                ArgValue::Many(list) => out.extend(list.iter().cloned()),
            },
            Argument::Conditional { .. } => {}
        }
    }
    out
}

fn variables(v: &VersionJson, ctx: &LaunchContext) -> HashMap<&'static str, String> {
    let s = |p: &Path| p.to_string_lossy().into_owned();
    let sep = ctx.env.classpath_separator();
    let classpath = ctx.classpath.iter().map(|p| s(p)).collect::<Vec<_>>().join(sep);
    let a = &ctx.account;
    HashMap::from([
        ("auth_player_name", a.name.clone()),
        ("auth_uuid", a.uuid.clone()),
        ("auth_access_token", a.access_token.clone()),
        ("auth_session", format!("token:{}:{}", a.access_token, a.uuid)),
        ("auth_xuid", a.xuid.clone()),
        ("clientid", "0".to_string()),
        ("user_type", a.user_type.clone()),
        ("user_properties", "{}".to_string()),
        ("version_name", v.id.clone()),
        ("version_type", v.kind.clone().unwrap_or_else(|| "release".into())),
        ("game_directory", s(&ctx.game_dir)),
        ("assets_root", s(&ctx.assets.assets_root)),
        ("game_assets", s(&ctx.assets.game_assets)),
        ("assets_index_name", ctx.assets.index_id.clone()),
        ("natives_directory", s(&ctx.natives_dir)),
        ("library_directory", s(&ctx.libraries_dir)),
        ("classpath", classpath),
        ("classpath_separator", sep.to_string()),
        ("launcher_name", "hengst-client".to_string()),
        ("launcher_version", env!("CARGO_PKG_VERSION").to_string()),
        ("resolution_width", "854".to_string()),
        ("resolution_height", "480".to_string()),
    ])
}

/// Replaces `${key}` with known values; unknown placeholders stay untouched.
pub fn substitute(s: &str, vars: &HashMap<&str, String>) -> String {
    let mut out = String::with_capacity(s.len());
    let mut rest = s;
    while let Some(start) = rest.find("${") {
        out.push_str(&rest[..start]);
        let after = &rest[start + 2..];
        match after.find('}') {
            Some(end) => {
                let key = &after[..end];
                match vars.get(key) {
                    Some(value) => out.push_str(value),
                    None => {
                        out.push_str("${");
                        out.push_str(key);
                        out.push('}');
                    }
                }
                rest = &after[end + 1..];
            }
            None => {
                out.push_str(&rest[start..]);
                rest = "";
            }
        }
    }
    out.push_str(rest);
    out
}

pub struct LaunchOptions {
    pub version: String,
    /// Instance folder name; defaults to the version id.
    pub instance: Option<String>,

    /// Use this java executable instead of a managed runtime.

    pub java: PathBuf,
    pub args: Vec<String>,
    pub game_dir: PathBuf,
    pub version_id: String,

/// Downloads everything a version needs and builds the command line.
pub async fn prepare(paths: &Paths, opts: &LaunchOptions, ep: &Endpoints) -> Result<Prepared> {
    let dl = Downloader::new(http_client());
    let env = Env::current();

    let manifest = fetch_manifest(dl.client(), paths, &ep.manifest).await?;
    let entry = manifest
        .find(&opts.version)
        .ok_or_else(|| Error::UnknownVersion(opts.version.clone()))?
        .clone();
    let v = fetch_version(&dl, paths, &entry).await?;

    let game_dir = paths.instance(opts.instance.as_deref().unwrap_or(&v.id));
    tokio::fs::create_dir_all(&game_dir).await?;

    let libs = libraries::resolve(&v.libraries, &env, paths);
    let mut downloads = libs.downloads.clone();
    let mut classpath = libs.classpath.clone();
    if let Some(client) = v.downloads.as_ref().and_then(|d| d.client.as_ref()) {
        let jar = paths.client_jar(&v.id);
        downloads.push(Download { url: client.url.clone(), path: jar.clone(), sha1: Some(client.sha1.clone()) });
        classpath.push(jar);
    }
    let log_config = v.logging.as_ref().and_then(|l| l.client.as_ref()).map(|c| {
        let p = paths.log_config(&c.file.id);
        downloads.push(Download { url: c.file.url.clone(), path: p.clone(), sha1: Some(c.file.sha1.clone()) });
        p
    });
    dl.fetch_all(downloads).await?;

    let assets = match &v.asset_index {
        Some(index) => install_assets(&dl, paths, index, &game_dir, &ep.resources).await?,
        None => AssetsLayout { index_id: "legacy".into(), assets_root: paths.assets(), game_assets: paths.assets() },
    };

    let natives_dir = game_dir.join(".natives").join(&v.id);
    if natives_dir.exists() {
        tokio::fs::remove_dir_all(&natives_dir).await?;
    }
    libraries::extract_natives(&libs.natives, &natives_dir)?;

    let java = match &opts.java {
        Some(j) => j.clone(),
        None => ensure_runtime(&dl, paths, &env, &component_for(&v), &ep.runtime_index).await?,
    };

    let ctx = LaunchContext {
        account: opts.account.clone(),
        game_dir: game_dir.clone(),
        natives_dir,
        libraries_dir: paths.libraries(),
        classpath,
        assets,
        log_config,
        env,
        memory_mb: opts.memory_mb,
    };
    Ok(Prepared { java, args: build_args(&v, &ctx), game_dir, version_id: v.id.clone() })
}

/// Starts the game and waits for it to exit. Output goes to the current console.
pub async fn run(p: &Prepared) -> Result<i32> {
    let status = tokio::process::Command::new(&p.java)
        .args(&p.args)
        .current_dir(&p.game_dir)
        .status()
        .await?;
    Ok(status.code().unwrap_or(-1))
}

        /// Version id, or `latest` / `latest-snapshot`
        version: String,
        #[arg(long)]
        instance: Option<String>,
        /// Offline development name (Microsoft login arrives in phase 2)
        #[arg(long, default_value = "Dev")]
        username: String,
        #[arg(long)]
        java: Option<PathBuf>,
        #[arg(long, default_value_t = 2048)]
        memory: u32,
        /// Download everything and print the command line instead of starting
        #[arg(long)]
        dry_run: bool,
    },
}

#[derive(Clone, Copy, ValueEnum)]
enum KindFilter {
    Release,
    Snapshot,
    OldBeta,
    OldAlpha,
    All,
}

impl KindFilter {
    fn matches(self, kind: VersionKind) -> bool {
        match self {
            KindFilter::All => true,
            KindFilter::Release => kind == VersionKind::Release,
            KindFilter::Snapshot => kind == VersionKind::Snapshot,
            KindFilter::OldBeta => kind == VersionKind::OldBeta,
            KindFilter::OldAlpha => kind == VersionKind::OldAlpha,
        }
    }
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let cli = Cli::parse();
    let paths = Paths::new(cli.home.unwrap_or_else(Paths::default_root));
    match cli.cmd {
        Cmd::Versions { kind, limit } => {
            let manifest = fetch_manifest(&http_client(), &paths, MANIFEST_URL).await?;
            for v in manifest.versions.iter().filter(|v| kind.matches(v.kind)).take(limit) {
                println!("{:<28} {:?}", v.id, v.kind);
            }
        }
        Cmd::Launch { version, instance, username, java, memory, dry_run } => {
            let opts = LaunchOptions {
                version,
                instance,
                account: Account::offline(&username),
                java,
                memory_mb: memory,
            };
            let prepared = prepare(&paths, &opts, &Endpoints::default()).await?;
            if dry_run {
                println!("{}", prepared.java.display());
                for arg in &prepared.args {
                    println!("  {arg}");
                }
                return Ok(());
            }
            if !cfg!(feature = "dev-offline") {
                bail!("starting the game requires Microsoft login (phase 2); build with --features dev-offline for local testing");
            }
            let code = run(&prepared).await?;
            std::process::exit(code);
        }
    }
    Ok(())
}
